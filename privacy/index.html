Privacy for Wordlist Arcade

Last updated: 28 August 2026.

This notice explains browser storage, class links, and lesson files.

What stays on your device

The vocabulary draft you type is saved in your browser’s local storage so it is there when you return. You can remove it at any time with “Clear list,” by clearing this site’s browser data, or by using private browsing.

What is inside a shared link

When you copy a class link, the list name, words, and meanings are compressed into the part of the URL after the #. Browsers do not send that hash fragment to our web server. Anyone with the link can read and play the list. Do not put names, grades, student details, or confidential material in a list.

Lesson files

When you download a lesson file, it contains the same list name, words, and meanings. It stays on your device until you choose a person, app, or location to send it to. Importing a lesson file reads it in this browser only.

What we collect

No account, cookies, advertising trackers, analytics scripts, or third-party runtime services are used. Hosting may create short-lived server logs for security and reliable delivery. These logs can include an IP address, request time, and browser information.

Children

There are no fields for student names or contact details. Teachers should share only classroom content and supervise use according to their school’s policies.

Questions

For privacy questions, contact the site operator through Sociobot (external site). You can return to Wordlist Arcade at any time.
